ETAPA 1 DE 9

Consumo da API Pública Open-Meteo

O projeto começa pelo dashboard, que consome dados meteorológicos da API (Application Programming Interface) pública Open-Meteo usando apenas HTML e JavaScript. Nesta etapa ainda não existe banco de dados nem backend, toda a comunicação acontece diretamente entre o navegador da web e o servidor da Open-Meteo.

Passo a Passo

Primeiro vamos criar a pasta do projeto, depois a tela do dashboard com os espaços reservados para os gráficos, e por fim o JavaScript que busca os dados na API pública e desenha os gráficos com a biblioteca ECharts.

Passo 1 - Crie a pasta do projeto

Abra o VS Code e crie uma nova pasta vazia chamada de Monitoramento Meteorológico Integrado. Dentro dela, crie duas subpastas, uma chamada de templates, que vai guardar os arquivos de HTML, e outra chamada de static, que vai guardar os arquivos de JavaScript.

Abrindo a pasta no VS Code No VS Code, clique em Arquivo → Abrir Pasta e selecione a pasta do projeto. Isso garante que o terminal integrado do editor de código já abra na pasta correta.

Passo 3 - Crie o JavaScript do dashboard

Dentro da pasta static, crie um arquivo chamado de dashboard.js com o conteúdo abaixo:

javascript — dashboard.js
// Guarda as leituras que chegarem da API de Meteorologia.
const leituras = {};

// Coordenadas do local de interesse.
const cidades = {
    "botucatu": { latitude: -22.48, longitude: -48.45 },
    "pardinho": { latitude: -23.08, longitude: -48.37 },
    "sao-manuel": { latitude: -22.73, longitude: -48.57 },
    "itatinga": { latitude: -23.10, longitude: -48.61 },
    "avare": { latitude: -23.10, longitude: -48.93 }
}

// Define o objeto de HTML que é o seletor de cidade.
const seletorCidade = document.getElementById("cidade"); 

// Event Listener que aguarde uma mudança no seletor de cidade.
seletorCidade.addEventListener("change", function(){

    // Busca as coordenadas da cidade selecionada.
    let local = cidades[seletorCidade.value];

    // Carrega as coordenadas geográficas em variáveis para manipulação.
    let latitude = local.latitude;
    let longitude = local.longitude;

    // Mostra as coordenadas geográficas.
    document.getElementById("coordenadas").textContent =
    "Latitude: " + latitude + " e Longitude: " + longitude;

    
    // Função que consulta os dados meteorológicos do Open-Meteo.
    function lerDados() {

        const url = "https://api.open-meteo.com/v1/forecast?latitude=" + latitude +
                    "&longitude=" + longitude + "&current=temperature_2m,relative_humidity_2m" +
                    "&minutely_15=temperature_2m" +
                    "&timezone=America/Sao_Paulo";

        return fetch(url);
    }

    // Desenha um gráfico da temperatura do ar.
    function exibirTemperatura (valor) {

        const grafico = echarts.init(document.getElementById("grafico-temperatura"));

        grafico.setOption({
            series: [
                {
                    type: "gauge",
                    min: 0,
                    max: 50,
                    detail: { formatter: "{value} °C" },
                    data: [{ value: valor }]
                }
            ]
        });
    }

    // Desenha um gráfico da umidade relativa.
    function exibirUmidade (valor) {

        const grafico = echarts.init(document.getElementById("grafico-umidade"));

        grafico.setOption({
            series: [
                {
                    type: "gauge",
                    min: 0,
                    max: 100,
                    detail: { formatter: "{value} %" },
                    data: [{ value: valor }]
                }
            ]
        });
    }

    // Desenha um gráfico da temperatura do ar ao longo do dia.
    function exibirTemperaturaDiaria (horarios, valores) {

        const grafico = echarts.init(document.getElementById("grafico-temperatura-diaria"));

        grafico.setOption({

            // Exibe informações ao passar o mouse no gráfico.
            tooltip: { trigger: "axis" },

            // Informações do eixo horizontal (horários).
            xAxis: {
                type: "category",
                data: horarios,
                boundaryGap: false
            },

            // Informações do eixo vertical (temperaturas do ar).
            yAxis: {
                type: "value",
                name: "Temperatura (°C)"
            },

            // Configura o zoom nos dados.
            dataZoom: [
                { type: "inside" },
                {}
            ],

            // Exibe os dados de temperatura do ar ao longo do dia.
            series: [{
                type: "line",
                data: valores,
                symbol: "none",
                areaStyle: {}
            }]
        });
    }

    // Vincula os dados meteorológicos com os gráficos.
    lerDados()
        .then(function (resposta) {

            // Lê os dados meteorológicos e salva em um objeto.
            return resposta.json();
        })
        .then(function (dados) {

            // Guarda os dados meteorológicos atuais.
            leituras.temperatura = dados.current.temperature_2m;
            leituras.umidade = dados.current.relative_humidity_2m;

            // Exibe a hora da coleta dos dados.
            let horaAtual = dados.current.time;
            document.getElementById("hora-coleta").textContent = horaAtual;

            // Alimenta os gráficos.
            exibirTemperatura(leituras.temperatura);
            exibirUmidade(leituras.umidade);

            // Vetores para criar o gráfico de temperatura do ar diária.
            let horarios = [];
            let valores = [];

            // Loop que percorre os dados e preenche os vetores.
            for (let i = 0; i < dados.minutely_15.time.length; i++) {

                // Filtra os dados para exibir apenas até a hora atual.
                if (dados.minutely_15.time[i] <= horaAtual) {

                    horarios.push(dados.minutely_15.time[i]);
                    valores.push(dados.minutely_15.temperature_2m[i]);
                }

            }

            // Exibe o gráfico de temperatura do ar diária.
            exibirTemperaturaDiaria(horarios, valores);
        });
});

Passo 4 - Compreender o consumo da API pública

  • cidades é um objeto que relaciona o valor de cada opção do seletor de cidade com a latitude e a longitude daquela cidade.
  • addEventListener("change", ...) executa todo o código sempre que o usuário escolhe uma cidade diferente no seletor.
  • lerDados() monta a URL da Open-Meteo com as coordenadas da cidade e os parâmetros desejados: current para a temperatura do ar e a umidade relativa atuais, minutely_15 para a temperatura do ar a cada 15 minutos, e timezone para receber os horários no fuso horário de Brasília.
  • fetch(url) faz a requisição para a API pública e devolve uma promessa (Promise). O primeiro .then() converte a resposta para JSON (JavaScript Object Notation) e o segundo .then() recebe os dados já convertidos.
  • echarts.init() associa um gráfico a uma <div> do HTML, e setOption() define o tipo do gráfico (gauge para os mostradores e line para a linha diária) e os dados exibidos.
  • A comparação dados.minutely_15.time[i] <= horaAtual mantém no gráfico diário apenas os horários que já aconteceram, descartando a previsão para o restante do dia.

Construção do Banco de Dados

Com o dashboard funcionando, o próximo objetivo é permitir que cada usuário tenha uma conta no sistema computacional. Para isso, os dados dos usuários precisam ser guardados em um banco de dados MySQL.

Etapa de copiar e colar O foco deste projeto é o frontend. Os códigos de banco de dados e de backend desta etapa são fornecidos prontos, basta copiá-los e colá-los nos arquivos indicados.

Passo a Passo

Passo 1 - Crie o arquivo do banco de dados

Na raiz da pasta do projeto, crie um arquivo chamado de schema.sql com o conteúdo abaixo:

sql — schema.sql
-- Cria e define o uso do banco de dados.
DROP DATABASE IF EXISTS meteorologia_db;
CREATE DATABASE meteorologia_db;
USE meteorologia_db;

-- Cria a tabela para armazenar dados dos usuários.
CREATE TABLE usuario (
    id INT NOT NULL PRIMARY KEY AUTO_INCREMENT,
    nome VARCHAR(100) NOT NULL,
    cpf VARCHAR(14) NOT NULL UNIQUE,
    email VARCHAR(100) NOT NULL UNIQUE,
    senha VARCHAR(255) NOT NULL,
    telefone VARCHAR(20),
    data_nascimento DATE,
    criado_em DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);

Passo 2 - Execute o arquivo no MySQL Workbench

Abra o MySQL Workbench, conecte-se ao servidor local, cole o conteúdo do schema.sql em uma nova aba de consulta e clique no ícone do raio para executar todo o conteúdo.

Atenção ao DROP DATABASE A primeira linha apaga o banco de dados meteorologia_db caso ele já exista. Se você executar esse arquivo novamente no futuro, todos os usuários cadastrados serão perdidos.

Passo 3 - Compreender a tabela criada

  • AUTO_INCREMENT faz o MySQL gerar automaticamente o id de cada novo usuário.
  • UNIQUE nas colunas cpf e email impede que dois usuários sejam cadastrados com o mesmo CPF ou com o mesmo e-mail.
  • senha VARCHAR(255) é maior do que uma senha comum porque a coluna vai guardar a senha criptografada (hash), que é um texto bem mais longo.
  • criado_em recebe automaticamente a data e a hora do cadastro, graças ao DEFAULT CURRENT_TIMESTAMP.

import mysql.connector

# Biblioteca para leitura de variáveis de ambiente.
import os
from dotenv import load_dotenv

# Carrega as variáveis do arquivo .env
load_dotenv()

# Função responsável pela conexão com o banco.
def database_connection():

    return mysql.connector.connect(

        user=os.getenv("DB_USER"),
        password=os.getenv("DB_PASSWORD"),
        database=os.getenv("DB_NAME")
    )

Passo 4 - Crie o arquivo de backend

Na raiz da pasta do projeto, crie um arquivo chamado de app.py com o conteúdo abaixo:

python — app.py
# Bibliotecas para arquitetura de aplicações da web.
from flask import Flask, request, jsonify

# Biblioteca para criptografar senhas.
from werkzeug.security import generate_password_hash, check_password_hash

# Biblioteca para interação do frontend com o backend.
from flask_cors import CORS

# Biblioteca para autenticação do Token da Web (JWT).
from flask_jwt_extended import JWTManager, create_access_token, jwt_required, get_jwt_identity

# Biblioteca para manipular datas.
from datetime import timedelta

# Módulo de conexão com o banco de dados.
from database import database_connection

# Biblioteca para leitura de variáveis de ambiente.
import os
from dotenv import load_dotenv

# Captura as variáveis de ambiente.
load_dotenv()

# Inicia a aplicação da web.
app = Flask(__name__)

# Permite que sejam feitas requisições de fora.
CORS(app)

# Configurações do Token da Web (JWT).
app.config["JWT_SECRET_KEY"] = os.getenv("JWT_SECRET_KEY")
app.config["JWT_ACCESS_TOKEN_EXPIRES"] = timedelta(hours=8)

# Inicializa o gerenciador de Tokens da Web (JWT).
jwt = JWTManager(app)


# -------------------------
# Executa a aplicação da web com modo de depuração ativo.
if __name__ == "__main__":

    app.run(debug=True)

Passo 5 - Compreender a estrutura do backend

  • load_dotenv() lê o arquivo .env, e os.getenv() recupera cada valor guardado nele.
  • database_connection() centraliza a conexão com o banco de dados em um único lugar, que será reaproveitado por todas as rotas.
  • CORS(app) é necessário porque o frontend roda no Live Server (porta 5500) e o backend roda no Flask (porta 5000). Sem o CORS (Cross-Origin Resource Sharing), o navegador da web bloquearia as requisições entre as duas portas.
  • JWT_ACCESS_TOKEN_EXPIRES define que o token da web (JWT, JSON Web Token) gerado no login vale por 8 horas.

Rotas de Backend para Cadastro e Login

Com o backend rodando, vamos criar as duas primeiras rotas, uma para cadastrar um novo usuário e outra para fazer login. Essas rotas formam a API local que será consumida pelo frontend nas próximas etapas.

Etapa de copiar e colar O foco deste projeto é o frontend. Os códigos de banco de dados e de backend desta etapa são fornecidos prontos, basta copiá-los e colá-los nos arquivos indicados.

Passo a Passo

Passo 1 - Adicione a rota de login

No arquivo app.py, logo abaixo da linha jwt = JWTManager(app), adicione a rota abaixo:

python — app.py
# -------------------------
# Rota para fazer login.
@app.route("/api/login", methods=["POST"])
def login():

    # Recebe os dados do frontend.
    dados = request.get_json()
    cpf = dados.get("cpf")
    senha = dados.get("senha")

    # Abre uma conexão com o banco de dados.
    link = database_connection()
    cursor = link.cursor(dictionary=True)

    # Roda o SQL para buscar os dados do usuário.
    cursor.execute("SELECT * FROM usuario WHERE cpf = %s", (cpf,))
    usuario = cursor.fetchone()

    # Fecha a conexão com o banco de dados.
    cursor.close()
    link.close()

    # Verifica se o usuário existe e se a senha está correta.
    if not usuario or not check_password_hash(usuario["senha"], senha):

        return jsonify({"erro": "CPF ou senha inválidos..."}), 401

    # Gera o token da web (JWT) com o ID do usuário.
    token = create_access_token(identity=str(usuario["id"]))

    return jsonify({"token": token, "nome": usuario["nome"]}), 200

Passo 2 - Adicione a rota de cadastro de usuário

Logo abaixo da rota de login, adicione a rota abaixo:

python — app.py
# -------------------------
# Rota para cadastrar um novo usuário (cadastro público).
@app.route("/api/usuarios", methods=["POST"])
def cadastrar_usuario():

    # Recebe os dados do frontend.
    dados = request.get_json()
    nome = dados.get("nome")
    cpf = dados.get("cpf")
    email = dados.get("email")
    senha = dados.get("senha")
    telefone = dados.get("telefone")
    data_nascimento = dados.get("data_nascimento")

    # Criptografa a senha.
    senha_hash = generate_password_hash(senha)

    # Abre uma conexão com o banco de dados.
    link = database_connection()
    cursor = link.cursor(dictionary=True)

    # Verifica se o CPF ou e-mail já estão cadastrados.
    cursor.execute("SELECT id FROM usuario WHERE cpf = %s OR email = %s", (cpf, email))
    if cursor.fetchone():
        cursor.close()
        link.close()
        return jsonify({"erro": "CPF ou e-mail já cadastrados..."}), 409

    # Roda o SQL para cadastrar o usuário.
    cursor.execute("""
        INSERT INTO usuario (nome, cpf, email, senha, telefone, data_nascimento)
        VALUES (%s, %s, %s, %s, %s, %s)
    """, (nome, cpf, email, senha_hash, telefone, data_nascimento))

    link.commit()

    # Fecha a conexão com o banco de dados.
    cursor.close()
    link.close()

    return jsonify({"mensagem": "Usuário cadastrado com sucesso!"}), 201

Passo 3 - Compreender as rotas da API local

Do ponto de vista do frontend, o que importa é saber o endereço de cada rota, o que enviar e o que esperar de volta:

  • POST /api/usuarios recebe nome, cpf, email, senha, telefone e data_nascimento. Devolve 201 com uma mensagem quando o cadastro dá certo, ou 409 com um erro quando o CPF ou o e-mail já existem.
  • POST /api/login recebe cpf e senha. Devolve 200 com o token e o nome do usuário quando os dados estão corretos, ou 401 com um erro quando não estão.
  • generate_password_hash criptografa a senha antes de gravá-la no banco de dados, e check_password_hash compara a senha digitada no login com essa versão criptografada.
  • create_access_token gera o token da web (JWT) que vai identificar o usuário nas próximas requisições.
Reinício automático do backend Como o app.py roda com debug=True, o Flask reinicia sozinho sempre que o arquivo é salvo. Se o terminal exibir algum erro, confira se as rotas foram coladas antes do bloco que executa a aplicação da web.

javascript — mascaras.js
// Captura os campos que receberão máscara.
const campoCpf = document.getElementById("cpf");
const campoTelefone = document.getElementById("telefone");

// Aplica a máscara de CPF: 000.000.000-00
function mascaraCpf(valor) {

    // Mantém somente os números e limita a 11 dígitos.
    valor = valor.replace(/\D/g, "").slice(0, 11);

    // Insere o ponto após o terceiro dígito.
    valor = valor.replace(/(\d{3})(\d)/, "$1.$2");

    // Insere o ponto após o sexto dígito.
    valor = valor.replace(/(\d{3})(\d)/, "$1.$2");

    // Insere o traço antes dos dois últimos dígitos.
    valor = valor.replace(/(\d{3})(\d{1,2})$/, "$1-$2");

    return valor;
}

// Aplica a máscara de telefone: (00) 00000-0000
function mascaraTelefone(valor) {

    // Mantém somente os números e limita a 11 dígitos.
    valor = valor.replace(/\D/g, "").slice(0, 11);

    // Insere os parênteses ao redor do DDD.
    valor = valor.replace(/(\d{2})(\d)/, "($1) $2");

    // Insere o traço antes dos quatro últimos dígitos.
    valor = valor.replace(/(\d{4,5})(\d{4})$/, "$1-$2");

    return valor;
}

// Formata o CPF enquanto o usuário digita.
campoCpf.addEventListener("input", function () {

    campoCpf.value = mascaraCpf(campoCpf.value);
});

// Aplica a máscara de telefone apenas se o campo existir na página atual.
if (campoTelefone) {

    // Formata o telefone enquanto o usuário digita.
    campoTelefone.addEventListener("input", function () {

        campoTelefone.value = mascaraTelefone(campoTelefone.value);
    });
}

javascript — cadastro.js
// Endereço base do backend local.
const API = "http://localhost:5000";

// Captura o botão de cadastro.
const botaoCadastrar = document.getElementById("botao-cadastrar");

// Exibe uma mensagem de status na tela (alerta do Bootstrap).
function exibirMensagem(texto, tipo) {

    const mensagem = document.getElementById("mensagem");

    mensagem.innerHTML =
        '<div class="alert alert-' + tipo + '">' + texto + "</div>";
}

// Envia os dados do formulário para o backend.
async function cadastrar() {

    // Monta o objeto com os dados digitados.
    const usuario = {
        nome: document.getElementById("nome").value,
        cpf: document.getElementById("cpf").value,
        email: document.getElementById("email").value,
        senha: document.getElementById("senha").value,
        telefone: document.getElementById("telefone").value || null,
        data_nascimento: document.getElementById("data-nascimento").value || null
    };

    // Verifica se os campos obrigatórios foram preenchidos.
    if (!usuario.nome || !usuario.cpf || !usuario.email || !usuario.senha) {

        exibirMensagem("Preencha todos os campos obrigatórios...", "warning");
        return;
    }

    // Verifica se a senha e a confirmação de senha são iguais.
    const confirmarSenha = document.getElementById("confirmar-senha").value;

    if (usuario.senha !== confirmarSenha) {

        exibirMensagem("As senhas não coincidem...", "warning");
        return;
    }

    try {

        // Envia a requisição de cadastro para o backend.
        const resposta = await fetch(API + "/api/usuarios", {
            method: "POST",
            headers: { "Content-Type": "application/json" },
            body: JSON.stringify(usuario)
        });

        // Lê o corpo da resposta em formato JSON.
        const dados = await resposta.json();

        // Verifica o status da resposta.
        if (resposta.ok) {

            // Cadastro realizado com sucesso.
            exibirMensagem(dados.mensagem, "success");

            // Redireciona para o login após 2 segundos.
            setTimeout(function () {
                window.location.href = "index.html";
            }, 2000);

        } else {

            // Erro tratado pelo backend.
            exibirMensagem(dados.erro, "danger");
        }

    } catch (erro) {

        // Erro de conexão com o backend.
        exibirMensagem("Não foi possível conectar ao servidor...", "danger");
    }
}

// Dispara o cadastro ao clicar no botão.
botaoCadastrar.addEventListener("click", cadastrar);

javascript — login.js
// Endereço base do backend local.
const API = "http://localhost:5000";

// Captura o botão de login.
const botaoEntrar = document.getElementById("botao-entrar");

// Exibe uma mensagem de status na tela (alerta do Bootstrap).
function exibirMensagem(texto, tipo) {

    const mensagem = document.getElementById("mensagem");

    mensagem.innerHTML =
        '<div class="alert alert-' + tipo + '">' + texto + "</div>";
}

// Envia os dados do formulário para o backend.
async function entrar() {

    // Monta o objeto com os dados digitados.
    const usuario = {
        cpf: document.getElementById("cpf").value,
        senha: document.getElementById("senha").value
    };

    // Verifica se os campos obrigatórios foram preenchidos.
    if (!usuario.cpf || !usuario.senha) {

        exibirMensagem("Preencha todos os campos obrigatórios...", "warning");
        return;
    }

    try {

        // Envia a requisição de login para o backend.
        const resposta = await fetch(API + "/api/login", {
            method: "POST",
            headers: { "Content-Type": "application/json" },
            body: JSON.stringify(usuario)
        });

        // Lê o corpo da resposta em formato JSON.
        const dados = await resposta.json();

        // Verifica o status da resposta.
        if (resposta.ok) {

            // Guarda o token da web (JWT) e o nome do usuário para as próximas requisições.
            localStorage.setItem("token", dados.token);
            localStorage.setItem("nome", dados.nome);

            window.location.href = "dashboard.html";

        } else {

            // Erro tratado pelo backend (ex.: 401, CPF ou senha inválidos).
            exibirMensagem(dados.erro, "danger");
        }

    } catch (erro) {

        // Erro de conexão com o backend.
        exibirMensagem("Não foi possível conectar ao servidor...", "danger");
    }
}

// Dispara o login ao clicar no botão.
botaoEntrar.addEventListener("click", entrar);

Passo 6 - Compreender o consumo da API local

  • Na etapa 1 usamos .then() para tratar a resposta do fetch. Aqui usamos async e await, que fazem a mesma coisa com uma escrita mais próxima de um código sequencial.
  • method: "POST", headers e body: JSON.stringify(usuario) enviam os dados do formulário para o backend no formato JSON.
  • resposta.ok é verdadeiro quando o backend devolve um código de sucesso (como 200 ou 201), e falso quando devolve um código de erro (como 401 ou 409).

  • No cadastro, a senha e a confirmação de senha são comparadas no próprio JavaScript, antes de qualquer requisição ser enviada ao backend.
  • No login, o token devolvido pelo backend é guardado no localStorage. O dashboard verifica se esse token existe e, se não existir, redireciona o usuário para a tela de login. A função sair() apaga o token e faz o caminho inverso.
Sobre o localStorage O localStorage é um espaço de armazenamento simples do próprio navegador da web, separado por site. Ele é adequado para guardar o token durante a sessão, mas não deve ser usado para dados sensíveis, pois qualquer script rodando na página consegue acessá-lo.

@jwt_required()

    link = database_connection()
    cursor = link.cursor(dictionary=True)

    cursor.execute("""
        SELECT id, nome, cpf, email, telefone, data_nascimento

    link.close()

    # Converte a data para o formato aceito pelo campo do tipo "date" (AAAA-MM-DD).
    if usuario["data_nascimento"]:
        usuario["data_nascimento"] = usuario["data_nascimento"].isoformat()

    return jsonify(usuario), 200

Passo 4 - Compreender as rotas da API local

  • GET /api/perfil devolve 200 com os dados do usuário logado (sem a senha).
  • PUT /api/perfil recebe os mesmos campos do cadastro e devolve 200 com uma mensagem, ou 409 quando o CPF ou o e-mail já pertencem a outro usuário.
  • DELETE /api/perfil exclui a conta do usuário logado e devolve 200 com uma mensagem.
  • As três rotas usam @jwt_required(), ou seja, só respondem quando a requisição envia um token válido no cabeçalho Authorization. Sem ele, o backend devolve 401 automaticamente.
  • get_jwt_identity() descobre de qual usuário é o token, em vez de receber um ID pela URL. Isso impede que um usuário veja, altere ou exclua os dados de outra pessoa apenas trocando um número no endereço.
Formato da data de nascimento O MySQL devolve o campo data_nascimento como um objeto de data da linguagem de programação Python, e o jsonify do Flask converte esse tipo de dado para o formato "Sat, 20 May 2000 00:00:00 GMT". O campo do tipo date do HTML só aceita o formato AAAA-MM-DD, por isso a rota buscar_perfil converte a data com .isoformat() antes de devolver a resposta.
Sobre a senha na alteração A senha só é atualizada quando o campo vem preenchido. Se o usuário deixar o campo de senha em branco, a rota alterar_perfil mantém a senha atual.

JavaScript para Editar e Excluir Dados do Usuário

Na última etapa, vamos criar o JavaScript da tela de perfil, que usa os métodos GET, PUT e DELETE para buscar, alterar e excluir os dados do usuário logado.

Passo a Passo

Passo 1 - Crie o JavaScript do perfil

Dentro da pasta static, crie um arquivo chamado de perfil.js com o conteúdo abaixo:

javascript — perfil.js
// Endereço base do backend local.
const API = "http://localhost:5000";

// Captura o botão de salvar alterações.
const botaoSalvar = document.getElementById("botao-salvar");

// Captura o botão de excluir a conta.
const botaoExcluir = document.getElementById("botao-excluir");

// Exibe uma mensagem de status na tela (alerta do Bootstrap).
function exibirMensagem(texto, tipo) {

    const mensagem = document.getElementById("mensagem");

    mensagem.innerHTML =
        '<div class="alert alert-' + tipo + '">' + texto + "</div>";
}

// Busca os dados do perfil do usuário logado e preenche o formulário.
async function carregarPerfil() {

    // Recupera o token da web (JWT) guardado no login.
    const token = localStorage.getItem("token");

    try {

        // Envia a requisição para buscar os dados do perfil.
        const resposta = await fetch(API + "/api/perfil", {
            method: "GET",
            headers: { "Authorization": "Bearer " + token }
        });

        // Lê o corpo da resposta em formato JSON.
        const dados = await resposta.json();

        // Verifica o status da resposta.
        if (resposta.ok) {

            // Preenche os campos do formulário com os dados do usuário.
            document.getElementById("nome").value = dados.nome;
            document.getElementById("cpf").value = dados.cpf;
            document.getElementById("email").value = dados.email;
            document.getElementById("telefone").value = dados.telefone || "";
            document.getElementById("data-nascimento").value = dados.data_nascimento || "";

        } else {

            // Erro tratado pelo backend.
            exibirMensagem(dados.erro, "danger");
        }

    } catch (erro) {

        // Erro de conexão com o backend.
        exibirMensagem("Não foi possível conectar ao servidor...", "danger");
    }
}

// Envia os dados alterados do formulário para o backend.
async function alterarPerfil() {

    // Recupera o token da web (JWT) guardado no login.
    const token = localStorage.getItem("token");

    // Monta o objeto com os dados digitados.
    const usuario = {
        nome: document.getElementById("nome").value,
        cpf: document.getElementById("cpf").value,
        email: document.getElementById("email").value,
        senha: document.getElementById("senha").value || null,
        telefone: document.getElementById("telefone").value || null,
        data_nascimento: document.getElementById("data-nascimento").value || null
    };

    // Verifica se os campos obrigatórios foram preenchidos.
    if (!usuario.nome || !usuario.cpf || !usuario.email) {

        exibirMensagem("Preencha todos os campos obrigatórios...", "warning");
        return;
    }

    // Verifica se a senha e a confirmação de senha são iguais.
    const confirmarSenha = document.getElementById("confirmar-senha").value;

    if (usuario.senha && usuario.senha !== confirmarSenha) {

        exibirMensagem("As senhas não coincidem...", "warning");
        return;
    }

    try {

        // Envia a requisição de alteração para o backend.
        const resposta = await fetch(API + "/api/perfil", {
            method: "PUT",
            headers: {
                "Content-Type": "application/json",
                "Authorization": "Bearer " + token
            },
            body: JSON.stringify(usuario)
        });

        // Lê o corpo da resposta em formato JSON.
        const dados = await resposta.json();

        // Verifica o status da resposta.
        if (resposta.ok) {

            // Alteração realizada com sucesso.
            exibirMensagem(dados.mensagem, "success");

        } else {

            // Erro tratado pelo backend.
            exibirMensagem(dados.erro, "danger");
        }

    } catch (erro) {

        // Erro de conexão com o backend.
        exibirMensagem("Não foi possível conectar ao servidor...", "danger");
    }
}

// Exclui a conta do usuário logado.
async function excluirPerfil() {

    // Solicita a confirmação do usuário antes de excluir.
    if (!confirm("Tem certeza que deseja excluir sua conta? Essa ação não pode ser desfeita.")) {

        return;
    }

    // Recupera o token da web (JWT) guardado no login.
    const token = localStorage.getItem("token");

    try {

        // Envia a requisição de exclusão para o backend.
        const resposta = await fetch(API + "/api/perfil", {
            method: "DELETE",
            headers: { "Authorization": "Bearer " + token }
        });

        // Lê o corpo da resposta em formato JSON.
        const dados = await resposta.json();

        // Verifica o status da resposta.
        if (resposta.ok) {

            // Remove os dados da sessão, pois a conta não existe mais.
            localStorage.removeItem("token");
            localStorage.removeItem("nome");

            // Exclusão realizada com sucesso.
            exibirMensagem(dados.mensagem, "success");

            // Redireciona para o login após 2 segundos.
            setTimeout(function () {
                window.location.href = "index.html";
            }, 2000);

        } else {

            // Erro tratado pelo backend.
            exibirMensagem(dados.erro, "danger");
        }

    } catch (erro) {

        // Erro de conexão com o backend.
        exibirMensagem("Não foi possível conectar ao servidor...", "danger");
    }
}

// Busca os dados do perfil assim que o HTML carrega.
carregarPerfil();

// Dispara a alteração ao clicar no botão.
botaoSalvar.addEventListener("click", alterarPerfil);

// Dispara a exclusão ao clicar no botão.
botaoExcluir.addEventListener("click", excluirPerfil);

Passo 2 - Compreender o JavaScript do perfil

  • carregarPerfil() é executada assim que a página abre e faz um GET para preencher o formulário com os dados atuais do usuário.
  • alterarPerfil() é disparada ao clicar no botão Salvar Alterações e faz um PUT com os dados do formulário. Se o campo de senha estiver vazio, ele é enviado como null e a senha atual é mantida.
  • excluirPerfil() é disparada ao clicar no botão Excluir Conta. Ela pede uma confirmação com confirm(), faz um DELETE e, como a conta deixou de existir, apaga o token do localStorage antes de voltar para a tela de login.
  • As três funções enviam o token no cabeçalho Authorization: Bearer <token>, que é o formato exigido pelo Flask-JWT-Extended nas rotas protegidas.
